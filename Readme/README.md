# MELYF

A life tracker software

## Core features

- A journal to write entries
- A money tracking interface
- A studylog to track studies

## How to install?

- Keep index.html, journal.html, money.html, studylog.html, journey.js in a single directory.
- Double click index.html.

## How it works

- In the main window, you'll see 3 buttons (Journal, Money Tracker, Study Log).
- Each button will lead you to individual websites.

## Technologies used
- HTML
- CSS
- Javascript
